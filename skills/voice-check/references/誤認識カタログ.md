# 音声入力の誤認識カタログ

実際に確認できた崩れの例。類似ケースの検知・修正に使う。

## 実害のある誤認識(修正対象)

| 正しい語 | 誤認識 | 種別 | 文脈例 |
|---|---|---|---|
| 要件(ようけん) | 容器(ようき) | 同音漢語 | 要件を整理して → 容器に整理し |
| 修正(しゅうせい) | 消費(しょうひ) | 同音漢語 | コードを修正したら |
| 動作確認(どうさかくにん) | 動作制限(どうさせいげん) | 同音漢語 | 動作確認のために |
| 保存(ほぞん) | 子供(こども) | 閉鎖音の短い漢語 | 保存ボタンを押す |
| 今朝(けさ) | 記者(きしゃ) | 短い語・子音k | 今朝のデータと比較 |
| 質問(しつもん) | そう | 指示語化 | 質問してください |

## 無害な言い換え(修正不要)

| 元の表現 | 認識結果 | 備考 |
|---|---|---|
| 〜の中の | 〜内の | 同義 |
| 読み込んで | 読み込み | 接続形の違い |
| っぽい | ようです | 同義の推量表現 |
| あるので | ありますので | 丁寧表現の差 |
| 返ってきたら | 返った場合 | 同義の条件文 |
| 照合して | 比較し | 同義 |
| 違いがあったら | 異なれば | 同義 |
| 表にして | 記載して | ニュアンス差あり(要判断) |

## 対策の基本3点

1. 短い漢語はゆっくりはっきり発音
2. 崩れやすい語は言い換える(今朝 → 今日の朝のデータ)
3. 認識結果に「変な名詞」がないかだけ目を通す
